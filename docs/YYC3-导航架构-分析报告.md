## 导航架构概述

YYC³ 企业管理系统采用**左侧主导航 + 顶部工具栏**的经典布局模式，基于 Next.js 14 App Router 实现路由管理。整个导航架构分为 **4大分区**，共 **32个功能模块**，覆盖企业运营管理的各个方面。

### 核心架构特点

- **布局模式**：固定左侧导航栏 + 顶部工具栏 + 主内容区
- **路由系统**：Next.js 14 App Router（文件系统路由）
- **主题系统**：每个功能模块拥有专属主题色
- **响应式设计**：支持桌面端、平板端、移动端适配
- **权限管理**：基于角色的访问控制（RBAC）

### 技术栈

- **前端框架**：Next.js 14 + React 18
- **路由管理**：Next.js App Router
- **状态管理**：React Context API
- **UI组件库**：shadcn/ui + Tailwind CSS
- **图标系统**：Lucide React
- **主题系统**：next-themes + 自定义主题色映射

## 页面功能详细说明

### 📊 数据中心 (/dashboard)

**功能概述**：
数据中心是系统的首页，提供企业运营数据的实时概览和关键指标展示。

**核心功能**：

- 实时数据统计卡片（用户数、客户数、任务数、项目数）
- 数据趋势图表（用户增长、客户增长、任务完成率）
- 快捷操作入口（新建客户、新建任务、新建项目）
- 待办事项提醒（今日任务、即将到期、未读通知）
- 系统状态监控（系统健康度、数据库状态、API状态）

**页面组件**：

- StatisticsDashboard - 统计仪表板组件
- KPI Cards - 关键指标卡片
- Trend Charts - 趋势图表
- Quick Actions - 快捷操作按钮
- Todo List - 待办事项列表

**数据来源**：

- 用户数据：`/api/users`
- 客户数据：`/api/customers`
- 任务数据：`/api/tasks`
- 项目数据：`/api/projects`

## 导航架构优化建议

### 1. 导航分类优化

**当前问题**：

- 32个模块集中在4个分区，部分分区模块过多
- "系统设置"和"平台设置"功能重叠
- "高级BI"和"数据分析"概念接近

**优化建议**：

- 将"运营中心"拆分为"业务运营"和"数据分析"两个分区
- 合并"系统设置"和"平台设置"为统一的"设置中心"
- 将"高级BI"重命名为"智能分析"，突出AI能力
- 增加"AI智能"分区，集中展示AI相关功能

### 2. 导航视觉优化

**当前问题**：

- 分组标题缺少视觉区分度
- 未激活状态的悬停反馈不够清晰
- 移动端边线显示效果不够明显

**优化建议**：

- 为分组标题添加左侧彩色装饰条
- 增加悬停状态的边线渐变动画效果
- 优化移动端边线显示效果，增加粗细度
- 为每个分区添加独特的背景色或图标

### 3. 导航功能优化

**当前问题**：

- 缺少快速访问和常用功能收藏
- 缺少全局搜索功能
- 缺少导航历史记录

**优化建议**：

- 增加"快速访问"区域，展示常用功能
- 实现全局搜索功能，支持跨模块搜索
- 添加导航历史记录，方便快速返回
- 支持自定义导航顺序和分组

### 4. 权限管理优化

**当前问题**：

- 当前所有用户看到相同的导航栏
- 未根据用户角色动态显示可访问模块

**优化建议**：

- 实现基于角色的导航显示
- 根据用户权限动态过滤导航项
- 添加权限不足的友好提示
- 支持管理员自定义用户导航权限

### 5. 性能优化

**当前问题**：

- 导航栏组件渲染可能存在性能问题
- 大量导航项可能导致首次加载缓慢

**优化建议**：

- 实现导航项的虚拟滚动
- 使用 React.memo 优化导航组件渲染
- 实现导航项的懒加载
- 优化主题色计算逻辑
