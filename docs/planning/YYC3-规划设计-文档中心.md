## 🛠️ 文档维护规范

### 命名约定

| 文档类型   | 命名格式                      | 示例                            |
| ---------- | ----------------------------- | ------------------------------- |
| 审查报告   | `{TYPE}_REPORT_{YYYYMMDD}.md` | CODE_QUALITY_REPORT_20250417.md |
| 改进规划   | `{TOPIC}.md`                  | OVERVIEW.md                     |
| 周报       | WEEKLY*SUMMARY*{YYYYMMDD}.md  | WEEKLY_SUMMARY_20250424.md      |
| 里程碑报告 | MILESTONE_PHASE{N}.md         | MILESTONE_PHASE1.md             |
| 模板       | TEMPLATE\_{TYPE}.md           | TEMPLATE_WEEKLY_SUMMARY.md      |

### 版本管理

- 所有文档使用Markdown格式
- 重要修改需在文档头部更新版本号和日期
- 定期归档旧版本（保留最近3个版本）
- 使用Git追踪文档变更历史

### 更新频率

| 文档类型     | 更新频率         | 负责人    |
| ------------ | ---------------- | --------- |
| 代码审查报告 | 每月或重大变更后 | Tech Lead |
| 改进规划     | 每阶段结束时     | PM        |
| 周报         | 每周五           | 全体成员  |
| 文档索引     | 新文档创建时     | Doc Owner |
