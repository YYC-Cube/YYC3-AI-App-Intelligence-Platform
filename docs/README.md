## 🧭 导航原则

| 原则            | 说明                                         |
| --------------- | -------------------------------------------- |
| **按领域分类**  | 同一主题的所有文档归入同一目录               |
| **文件名前缀**  | `YYC3-` 前缀标识项目专属文档，与开源依赖区分 |
| **README 索引** | 每个子目录含 README.md 作为入口              |
| **避免嵌套**    | 目录深度不超过 2 层                          |
